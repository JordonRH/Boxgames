# Party-game repository research

Reviewed 20 November 2026 in response to the request for simpler phone play, a Heads Up-style game, and a comedy card game.

The official [Heads Up listing](https://apps.apple.com/us/app/heads-up/id623592465) describes guessing a word held facing the other players, with correct/pass actions. The official [Cards Against Humanity rules](https://s3.amazonaws.com/cah/CAH_MainGame.pdf) describe private response cards and a rotating judge. Those references explain the requested familiar play formats; Boxgame uses independently written names, wording, content and presentation.

The resulting Boxgame choices are **Clue Crew** (spoken clues and big manual controls), **Blank Slate** (original prompt/response cards), and **Crowd Pick** (one-tap voting). No external app, runtime content service, commercial deck, or copied repository code is required.

No complete, clearly licensed, drop-in phone-and-TV Trivia Murder Party equivalent was verified in this search. Public visibility alone does not grant reuse rights; missing GitHub licence metadata is not proof that no permission exists elsewhere.

Boxgame's additions are **Blackout Run**, an outpost-power trivia/repair game with recoverable charge and no elimination, and **False Front**, odd-word definitions with private two-option truth/bluff duels. Both use independently written engines, names, rules, wording and presentation. No commercial quiz datasets, characters, narration, death/ghost finale, copied repository code or runtime third-party content API is included.

Factual references for the new starter packs: [NASA planets](https://science.nasa.gov/solar-system/planets/), [Te Papa insect/arachnid classification](https://www.tepapa.govt.nz/digital-museum/explore-digital-museum/your-bug-questions-answered/what-is-a-bug-insects-arachnids-and-myriapods), [NSW arachnids](https://fieldofmar-e.schools.nsw.gov.au/fact-sheets/invertebrates/arachnids-fact-sheet), and dictionary entries individually linked in `server/games/knowledge-content.ts`. Definitions and questions are original paraphrases of facts. Arithmetic puzzle answers are calculated locally. Sources are only linked after reveal; phones do not contact those sites unless a player opens a source link.

## Playtest revision — 20 November 2026

The feedback release replaces Blackout Run's easy questions with 24 independently worded medium/hard questions across six subjects. Every game draws three medium then three hard questions with no subject repeated. Facts were checked against [NASA Venus](https://science.nasa.gov/venus/venus-facts/), [Uranus](https://science.nasa.gov/uranus/facts/), [Neptune](https://science.nasa.gov/neptune/neptune-facts/), the Royal Society of Chemistry's [tungsten](https://periodic-table.rsc.org/element/74/tungsten), [bromine](https://periodic-table.rsc.org/element/35/bromine) and [antimony](https://periodic-table.rsc.org/element/51/antimony) pages, UNESCO entries for [Taj Mahal](https://whc.unesco.org/en/list/252/), [Machu Picchu](https://whc.unesco.org/en/list/274/), [Petra](https://whc.unesco.org/en/list/326/) and [Angkor](https://whc.unesco.org/en/list/668/), [Australian Museum platypus facts](https://australian.museum/learn/animals/mammals/platypus/), and author/title records at Project Gutenberg and the British Library linked in the question pack. No questions are copied from those sources. The maths questions and six repair-puzzle families use locally calculated answers. Difficulty labels are editorial estimates, not a claim of calibrated player performance.

Clue Crew now sends the live word only to clue-givers; the guesser receives a category and a nonce for passing. False Front has eight independently written placeholder examples. Blank Slate adds 48 original short response cards. Crowd Pick now requires three connected participants at start and to continue play. These changes introduce no new packages, content APIs, accounts, tracking or infrastructure configuration.

## Replayability expansion — 20 November 2026

Packs now contain 72 trivia questions (four at each difficulty in each of six subjects), 24 odd words, 64 original sentence prompts, 240 original response cards, 240 categorised clue words and 30 original project sets. New trivia facts use the NASA, Royal Society of Chemistry, UNESCO, Australian Museum and literary records linked next to each question. Sixteen new odd-word facts were checked against the individually linked Merriam-Webster entries; definitions and house bluffs are independently phrased. Original prompts/cards/scenarios and maths do not import third-party game packs.

Used content is bounded by the bundled packs and kept only in the room's memory. A host must explicitly permit repeats with a reset. Session scoring and feedback flags are also transient; there is no telemetry service, saved profile, external content API or new infrastructure dependency. Difficulty labels remain editorial estimates. Original wording, names and presentation remain Boxgame's own.
