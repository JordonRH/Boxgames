# Party-game repository research

Reviewed 20 November 2026 in response to the request for simpler phone play, a Heads Up-style game, and a comedy card game.

| Project                                                                       | Relevant findings                                                                                                                                        | Reuse decision                                                                                                                          |
| ----------------------------------------------------------------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------- | --------------------------------------------------------------------------------------------------------------------------------------- |
| [ubat-game](https://github.com/matzebond/ubat-game)                           | Browser forehead guessing, success/skip buttons, motion support, React/Preact with a Node backend. GitHub identifies AGPL-3.0; its last push is in 2018. | Reference the browser/manual-button approach; independently write our engine, interface and word list. No code, sounds or decks copied. |
| [Massive Decks](https://github.com/Lattyware/massivedecks)                    | Phone/PC/shared-display comedy cards, private games, custom decks, Docker deployment; Elm client and TypeScript server. AGPL-3.0 code.                   | Reference private hands, anonymous judging and shared-display behavior. Keep the existing Boxgame stack and original cards.             |
| [Node Against Humanity](https://github.com/WendellTech/Node-Against-Humanity) | Node-based self-hosted card game, rooms and JSON card-set support. GitHub identifies GPL-3.0.                                                            | Reference the deployment and room concept; no code or card packs imported.                                                              |
| [Pretend You’re Xyzzy](https://github.com/ajanata/PretendYoureXyzzy)          | Older Java/Tomcat card implementation, BSD-2-Clause code metadata; repository is archived. Its README describes limited server-version support.          | Historical reference; do not add this older stack or its bundled datasets to Boxgame.                                                   |

The official [Heads Up listing](https://apps.apple.com/us/app/heads-up/id623592465) describes guessing a word held facing the other players, with correct/pass actions. The official [Cards Against Humanity rules](https://s3.amazonaws.com/cah/CAH_MainGame.pdf) describe private response cards and a rotating judge. Those references explain the requested familiar play formats; Boxgame uses independently written names, wording, content and presentation.

The resulting Boxgame choices are **Clue Crew** (spoken clues and big manual controls), **Blank Slate** (original prompt/response cards), and **Crowd Pick** (one-tap voting). No external app, runtime content service, commercial deck, or copied repository code is required.
